网站托管与 Google 登录

本站由 GitHub Pages 提供静态文件，没有应用服务器或服务端数据库。GitHub 会收到常规网页请求中的信息，例如 IP 地址和浏览器发出的 User-Agent 请求头，并依照其隐私声明处理这些信息。

本站代码不设置 Cookie，也不包含分析、广告或追踪代码。本站代码加载的唯一第三方脚本是来自 accounts.google.com 的 Google Identity Services。配置有效的 Drive OAuth 客户端后，Drive 备份卡片靠近可视区域、卡片内的控件获得焦点或指针移入卡片时，应用可预加载该脚本。修改 Drive 登录设置、重试加载或使用 Gemini 的 Google OAuth 授权也可触发加载。

浏览器中的数据

应用在浏览器的 localStorage 中保存明文 API 密钥、API 资源设置、创作偏好、当前角色设计、设计库的自定义内容、提示词历史（含编辑和评价）、历史记录保留上限、云图库同步设置，以及是否显示生图面板。应用也在 localStorage 中记住你为 Google Drive 选择的是站点提供的 OAuth 客户端还是自己的客户端。如果你用自己的客户端成功连接，应用还会保存该客户端的 ID。生图偏好保存在 sessionStorage。本地生图历史保存在 IndexedDB，其中包括缓存的云图库缩略图和对应的 Drive 文件引用。应用不会将备份口令、云图库口令或 Google OAuth 访问令牌写入浏览器存储。同源脚本可读取 localStorage 和 IndexedDB 中的数据。使用同一 GitHub Pages 域名的不同项目路径属于同一来源。sessionStorage 还按浏览器标签页隔离。

生图请求

浏览器将提示词、生图参数、你提供的参考图和编辑素材，以及适用的 API 密钥或 Google OAuth 访问令牌，直接发送给你配置的服务（OpenAI、Google Gemini API、Google Vertex AI 或自定义网关）。如需了解相关服务如何处理请求，请查看该服务的条款和隐私政策。

如果服务返回图片网址而非图片数据，浏览器会直接从该地址下载图片，不携带 Cookie，也不发送来源页信息（Referrer）。

Google 用户数据

Google Drive 备份和云图库只请求 https://www.googleapis.com/auth/drive.appdata 权限。该权限仅允许应用访问它在你的 Drive 中专用的隐藏应用数据文件夹。浏览器将访问令牌直接发送给 Google Drive，仅为提供历史备份和云图库功能而访问其中的文件及其元数据（如文件标识、大小和创建时间），包括保存、列出、查看和恢复。

上传前，应用在浏览器内用你选择的口令加密历史备份（可包含提示词和本地生图记录）、云图库图片和记录清单。口令不会发送到 Drive。启用云图库自动同步后，应用可在图库解锁期间自动上传新生成的图片。

「Gemini · Google OAuth」是独立的生图资源类型。应用使用你自己的 OAuth 客户端请求 https://www.googleapis.com/auth/cloud-platform 权限，用令牌获取 Vertex AI 模型列表，并在你配置的 Google Cloud 项目中调用 Vertex AI 生图。两种 Google OAuth 流程的访问令牌都只保留在当前页面的内存中。

项目维护者不会通过本应用接收、存储、出售或共享这些数据。本应用不将这些数据用于广告或模型训练。本应用对从 Google API 获得的信息的使用及向其他应用的传输，均遵守 Google API 服务用户数据政策，包括其中的有限使用要求。

删除数据与撤销授权

清除浏览器中此来源的站点数据，即可删除保存在浏览器中的数据。如需删除云端备份和图库，请在 Google Drive 的「设置 → 管理应用」中找到授权时使用的应用，删除隐藏应用数据。如需撤销授权，请前往 Google 帐号权限页面，移除相应应用的访问权限。

Privacy Policy

Last updated 2026-11-26

Moonlight Theater helps you write character illustration prompts in Chinese and English. It can also generate images through a service you configure.

Hosting and Google sign-in

GitHub Pages serves the site's static files. The site has no application server or server-side database. GitHub receives ordinary web request information, such as IP addresses and any User-Agent headers browsers send, and handles it under its privacy statement.

The site's code sets no cookies and includes no analytics, advertising, or tracking code. It loads one third-party script, Google Identity Services, from accounts.google.com. When a valid Drive OAuth client is configured, the app can preload the script when the Drive backup card comes close to being visible, a control inside it receives focus, or the pointer moves onto it. Changing Drive sign-in settings, retrying the load, or authorizing Gemini through Google OAuth can also load the script.

Data in your browser

In your browser's localStorage, the app saves plain-text API keys, API resource settings, studio preferences, your current character design, design library customizations, prompt history (including edits and feedback), history retention limits, cloud gallery sync settings, and whether the image generation panel is shown. For Google Drive, it also saves your choice of the site's OAuth client or your own in localStorage. If you connect successfully with your own client, the app saves that client ID there too. Image-generation preferences are saved in sessionStorage. Local image-generation history, including cached cloud gallery thumbnails and their Drive file references, is saved in IndexedDB. The app does not write any backup passphrases, cloud gallery passphrases, or Google OAuth access tokens to browser storage. Scripts from the same origin can read data in localStorage and IndexedDB. Project paths on the same GitHub Pages domain share an origin. sessionStorage is also scoped to a browser tab.

Image generation requests

Your browser sends the prompt, generation settings, any reference images and editing materials you supply, and the applicable API key or Google OAuth access token directly to the service you configure (OpenAI, Google Gemini API, Google Vertex AI, or a custom gateway). See that service's terms and privacy policy for how it handles these requests.

If the service returns an image URL instead of image data, your browser downloads the image directly from that address without cookies or a referrer.

Google user data

Google Drive backup and the cloud gallery request only the https://www.googleapis.com/auth/drive.appdata scope, which gives the app access only to its own hidden application-data folder in your Drive. The browser sends the access token directly to Google Drive. The app accesses files and metadata (such as file IDs, sizes, and creation times) in that folder only to provide history backup and cloud gallery features, including storing, listing, viewing, and restoring data.

Before upload, the app uses a passphrase you choose to encrypt history backups (which can contain prompts and local image history), gallery images, and gallery manifests in your browser. It does not send the passphrase to Drive. If you enable automatic gallery sync, the app can upload new images automatically while the gallery is unlocked.

Gemini with Google OAuth is a separate image generation resource. The app uses your own OAuth client to request the https://www.googleapis.com/auth/cloud-platform scope. It uses that token to list Vertex AI models and call Vertex AI for image generation in your configured Google Cloud project. The app keeps both kinds of Google OAuth access token only in the current page's memory.

The project maintainer does not receive, store, sell, or share this data through the app. The app does not use it for advertising or model training. Moonlight Theater's use of information received from Google APIs, including any transfer to another app, complies with the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data and revoking access

Clear this origin's site data in your browser to remove data saved there. To delete cloud backups and the gallery, go to Settings → Manage apps in Google Drive, find the app you authorized, and delete its hidden app data. To revoke authorization, go to your Google Account permissions page and remove access for the relevant app.

Contact

For privacy questions, contact the project maintainer through the project issue tracker. Back to Moonlight Theater

プライバシーポリシー

最終更新日 2026-11-26

Moonlight Theater は、キャラクターイラスト用のプロンプトを中国語と英語で作成するためのツールです。設定したサービスを使って画像を生成することもできます。

サイトのホスティングと Google ログイン

このサイトは GitHub Pages で静的ファイルを配信しており、アプリケーションサーバーやサーバー側のデータベースはありません。GitHub は、IP アドレスやブラウザーが送信する User-Agent ヘッダーなど、通常のウェブリクエストに伴う情報を受け取り、同社のプライバシーに関する声明に従って取り扱います。

このサイトのコードは Cookie を設定せず、アクセス解析、広告、トラッキングのためのコードも含みません。読み込む外部スクリプトは、accounts.google.com が配信する Google Identity Services のみです。有効な Drive 用の OAuth クライアントが設定されている場合、Drive バックアップ欄が画面の表示範囲に近づいたとき、欄内の操作項目にフォーカスが移ったとき、またはポインターが欄内に入ったときに、スクリプトを事前に読み込むことがあります。Drive のログイン設定を変更したとき、読み込みをやり直したとき、Gemini 用に Google OAuth で認可するときにも読み込まれることがあります。

ブラウザー内に保存されるデータ

アプリは API キーを暗号化せずにブラウザーの localStorage に保存します。API リソースの設定、プロンプト作成時の設定、現在のキャラクターデザイン、デザインライブラリのカスタマイズ内容、プロンプトの履歴（編集内容や評価を含む）、履歴の保存上限、クラウドギャラリーの同期設定、画像生成パネルの表示状態もここに保存します。Google Drive への接続にサイトが用意した OAuth クライアントを使うか、利用者自身のクライアントを使うかの選択も localStorage に保存します。利用者自身のクライアントで接続に成功した場合は、そのクライアント ID も保存します。画像生成の設定は sessionStorage に保存します。端末上の画像生成履歴は IndexedDB に保存します。この履歴には、キャッシュしたクラウドギャラリーのサムネイルと、対応する Drive ファイルの参照情報も含まれます。バックアップやクラウドギャラリーのパスフレーズ、および Google OAuth アクセストークンは、ブラウザーのストレージに書き込みません。同じオリジンのスクリプトは localStorage と IndexedDB のデータを読み取れます。GitHub Pages では、同じドメイン上の異なるプロジェクトパスも同じオリジンに属します。sessionStorage はブラウザーのタブごとに分かれています。

画像生成時に送信するデータ

ブラウザーは、プロンプト、生成設定、利用者が指定した参照画像や編集用の素材、必要に応じて API キーまたは Google OAuth アクセストークンを、設定先のサービス（OpenAI、Google Gemini API、Google Vertex AI、またはカスタムゲートウェイ）に直接送信します。リクエストの取り扱いについては、そのサービスの利用規約とプライバシーポリシーをご確認ください。

サービスが画像データではなく画像 URL を返す場合、ブラウザーは Cookie やリファラーを送信せず、そのアドレスから画像を直接ダウンロードします。

Google ユーザーデータ

Google Drive のバックアップとクラウドギャラリーがリクエストするスコープは https://www.googleapis.com/auth/drive.appdata のみです。このスコープでアクセスできるのは、利用者の Drive にある、このアプリ専用の非表示のアプリケーションデータフォルダだけです。ブラウザーはアクセストークンを Google Drive に直接送信します。アプリがこのフォルダ内のファイルとメタデータ（ファイル ID、サイズ、作成日時など）にアクセスするのは、保存、一覧表示、閲覧、復元など、履歴バックアップとクラウドギャラリーの機能を提供するためだけです。

履歴バックアップ（プロンプトや端末上の画像生成履歴を含む場合があります）、ギャラリーの画像、ギャラリーの記録一覧は、利用者が選んだパスフレーズでブラウザー内で暗号化してからアップロードします。パスフレーズは Drive に送信しません。ギャラリーの自動同期を有効にすると、ギャラリーのロックが解除されている間は、新しく生成した画像が自動でアップロードされることがあります。

「Gemini · Google OAuth」は別の画像生成用リソースです。利用者自身の OAuth クライアントを使って https://www.googleapis.com/auth/cloud-platform スコープをリクエストします。アプリはそのトークンで Vertex AI のモデル一覧を取得し、設定された Google Cloud プロジェクトで Vertex AI に画像生成をリクエストします。いずれの Google OAuth アクセストークンも、現在開いているページのメモリにのみ保持します。

プロジェクトのメンテナーは、このアプリを通じてこれらのデータを受け取ることも、保存、販売、共有することもありません。アプリはこれらのデータを広告やモデルの学習には使用しません。Moonlight Theater は、Google API から取得した情報の利用および他のアプリへの転送について、利用制限の要件を含むGoogle API サービスのユーザーデータに関するポリシーを遵守します。

データの削除とアクセス権の取り消し

ブラウザーに保存されたデータを削除するには、このオリジンのサイトデータを消去してください。クラウドのバックアップとギャラリーを削除するには、Google Drive の「設定 → アプリの管理」でアクセスを許可したアプリを探し、非表示のアプリデータを削除してください。アクセス権を取り消すには、Google アカウントのアクセス権管理ページで対象のアプリのアクセス権を削除してください。
